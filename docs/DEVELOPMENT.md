# 开发指南

## 🚀 快速上手

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行 Web 版
```bash
streamlit run app_v2.py
```

### 3. 批量测试 Prompt
```bash
cd backend
python test_tools.py --api-key YOUR_API_KEY --mode batch
```

### 4. 对比两个 Prompt 版本
```bash
python test_tools.py --api-key YOUR_API_KEY --mode compare --case 0
```

## 🧪 优化 Prompt 的正确姿势

### 第一步：先跑批量测试
```bash
python test_tools.py --api-key XXX --mode batch
```
看看 4 个不同年龄/性别的案例，输出是不是符合预期。

### 第二步：对比优化效果
```bash
python test_tools.py --api-key XXX --mode compare --case 1
```
修改 Prompt 前后，对比同一个案例的输出，看看哪里变好了，哪里变差了。

### 第三步：真人测试
给 5-10 个朋友用，收集真实反馈：
- 「你觉得准吗？哪句话最戳你？」
- 「有没有哪里觉得说的不对？」
- 「看完你是什么感觉？」

### 第四步：迭代优化
根据反馈不断调整 Prompt，直到大部分人都说「哇，好准！」

## ✅ 好的运势解读的 5 个标准

### 1. 开头 3 句话就要「戳中」
用户看了前 3 句就应该觉得「哇，你懂我」。

✅ 正面例子：
> 你表面上看起来很乐观，好像什么都不在乎，但其实内心很敏感，很在意别人的看法。
> 你不喜欢麻烦别人，什么事都习惯自己扛。

❌ 反面例子：
> 你是一个很聪明的人。
> 你今年运势不错。

### 2. 平衡 - 有好有坏
不能全是好话，也不能全是坏话。
说好话的时候，说清楚「但是要注意...」
说问题的时候，说清楚「但是这也意味着...」

### 3. 具体 - 给可操作的建议
❌ 不要说「你要努力」
✅ 要说「建议你这段时间多跟比你年长 10 岁以上的人聊天，他们能给你意想不到的启发」

### 4. 符合年龄
25 岁的人关心的是事业起步、找对象，不要跟他说「注意身体」这种 40 岁才关心的话。
40 岁的人关心的是家庭、健康、中年危机，不要跟他说「勇敢去闯」这种话。

### 5. 结尾给希望
无论前面说了多少问题，最后一定要让用户觉得：
「只要我这么做，未来一定会越来越好的」

## ⚠️ 开发中的坑

### 1. 模型输出不稳定
同一个 Prompt，同一份输入，每次输出的质量可能差很多。
解决方法：
- 把 Prompt 写得更详细，约束更多
- 可以加一层「质量校验」，输出不好就重生成
- 温度不要太高，0.6-0.8 比较合适

### 2. 模型会说不该说的话
就算 Prompt 里写了不要说，有时候模型还是会说。
解决方法：
- 加一层输出审核，用关键词过滤
- 可以再调一个模型专门做「安全审核」
- 免责声明一定要放足

### 3. 中文排版问题
输出的时候，段落不要太长，多换行，方便手机阅读。
可以在 Prompt 里要求「段落不要太长，每 2-3 句就换行」。

### 4. 速度问题
生成 1000 字大概要 5-10 秒，用户可能会觉得慢。
解决方法：
- 用流式输出，一边生成一边显示（Streamlit 支持）
- 加个好看的加载动画，配一句有趣的文案
- 告诉用户「AI 正在为你排盘，请稍候...」
