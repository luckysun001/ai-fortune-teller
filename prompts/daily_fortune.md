# 今日运势卡片格式

## ✨ 今日运势：【运势等级，比如：上吉 / 中吉 / 小吉 / 平】

### 🔖 今日标签
3-5 个关键词，比如：适合摸鱼、适合表白、适合存钱、要少说话...

### 🍀 幸运值
- 幸运色：【颜色】
- 幸运数字：【数字】
- 幸运方位：【方位，比如：东北方、南方】
- 宜做的事：【2-3 件】
- 忌做的事：【1-2 件】

### 💌 今日建议
100-150 字，一句温暖、有智慧的话，结合今天的能量给用户一个小提醒。
可以是鼓励，可以是提醒，可以是一句让用户会心一笑的话。

### 🎯 今日小目标
给用户一个小小的、很容易完成的目标，比如：
- 今天喝够 8 杯水
- 给爸妈打个电话
- 今天不熬夜
- 夸一个人
- 整理一下桌面

# 原则
- 积极向上，即使是平运，也要说得有希望
- 有趣一点，不要太严肃，年轻人喜欢的风格
- 建议要实用，不要空泛
- 小目标一定要简单，让用户有成就感
